# 関連コード検索の固定サンプル

このコードは解析専用です。ビルド・実行・外部依存の取得は不要です。
Spring annotationは構文上の役割判定を確認するために記述しています。

起動・拡張接続後、このフォルダを選択してください。
`expected-searches.json`の質問、検索観点、主選択ファイルで検索し、期待ファイルが上位3件に入ることを確認します。
期待値は呼出し経路と各クラスの責務から定めており、計算結果の数値を写したものではありません。
係数を変更した比較では、同じ質問・snapshot・選択で順位と寄与を比較してください。

日本語コメントのない英語識別子だけのコードでは、日本語質問とのcosineが0になり得ます。
試す場合は独立したコピーを作ってコメントを削除し、再走査してください。
アプリが元コードを編集したり、質問を英訳したりすることはありません。
