# セクション切替UIの検証

## 変更

初回の中央案内とスタート、ファイル/生成/概算/翻訳/引継ぎのセクション切替、質問欄の70vw/20vhと丸角、長いリストの上位3件と残り折り畳みを追加した。関連順位・選択集合・計算式・認証・送信条件は変えない。独立したログイン機能は追加しない。

コンポーネントをunmountせずhiddenで表示だけを切り替える。質問・選択・予算・キー入力・ジョブ監視・会話を保持し、キー入力と回答コンポーネントは1個ずつ維持。workspace/snapshot変更による既存の失効処理は維持する。翻訳警告はコードでまとめ、該当fieldと未知の警告を折り畳みに保持する。翻訳成功後に英語を選ぶと「英語原文」と表示する。

## レビュー

専用reviewerが定義、AGENTS、詳細設計4/11/13/21章と差分をreadonlyで確認。P2として翻訳タブの再翻訳/取消操作エラーが生成タブにしか表示されない点を検出し、対応する。タブ移動によるstate/ジョブ消失、キー/回答複製、auth代替、候補欠落などの追加の確実な不具合はなし。

## ブラウザ確認と限界

Playwright MCPの未接続ページで初回案内、スタートによる案内終了、ファイル/生成/翻訳/引継ぎの切替と、未接続時にフォルダ選択を拒否することを確認。接続情報を移さず、認証を迂回していない。キーや接続トークンを出力していない。

接続済み実ブラウザで、編集中の質問→別セクション→復帰、主選択/概算/確定済み会話の保持、生成中の切替と監視継続、折り畳みからの追加選択を利用者が確認する。追加API通信を行わず、まず固定応答で試せる。ZIPは作成しない。

## 修正・検証結果

翻訳操作errorを隠れた生成領域から共有GenerationOperationFeedbackへ移し、生成/翻訳で1回だけ表示。翻訳タブの再翻訳/取消失敗がrole=alertで見える回帰を追加。専用再レビューで解消を確認し追加の確実な不具合なし。

Web55件と整形チェック・Lint・型チェック・build成功。MCPのブラウザ操作は未接続時の案内/切替に限定し、実API追加通信0。Javaを含むfresh build/CI結果はPRへ記録する。キー・認証・ユーザー変更をコミットしない。
