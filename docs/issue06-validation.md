## 式と具体例

排他的Unicode code point分類をTokenEstimatorへ集約した。ASCIIは空白・改行込み、Han/Hiragana/Katakana/CJK記号/全角形は日本語系、残りはその他。補助漢字・絵文字をサロゲート2文字として計数しない。

`T=ceil(0.35*N_ascii+1.50*N_ja+1.00*N_other)`。係数は設定変更可能な暫定値。0より大きく10以下を設定範囲とし、非現実的な係数による計算overflowを防ぐ。共通PromptMaterializerでsystem・schema・mode指示・参照ラベル・コード・原質問・末尾指示を一度だけ連結し、全文で一度切り上げる。HTTPヘッダー・APIキー・輸送JSONのescapeは含めない。

`M=max(ceil(0.20*T),512)`、`required=T+M`、許可は`budget>=required`。例：T=4,000、M=800、required=4,800。推定ちょうど4,000は不可、4,799は不可、4,800は許可。十進BigDecimalで切り上げる。

必須分は質問・固定指示等を含む主選択prompt、関連追加分は最終推定−必須分とし二重計上を避ける。出力上限2,048 tokensは入力予算と別。概算費用は`(T*P_input+2048*P_output)/1,000,000`、各費用を小数6桁へ切り上げて合計する。架空の入力2／出力4 USDならT=4,000で入力0.008000＋出力0.008192＝0.016192 USD。安全余裕は費用へ加算しない。思考・cache・翻訳は未計測／別課金と表示する。

実料金の既定値を採用していない。料金設定はモデルIDごとに入力単価・出力単価・通貨・確認日、任意context-limit。設定例は明記した架空モデルで無効なコメント。未知モデルは費用null＝料金不明で、tokens予算は使用できる。単価不足・負値・通貨／日付不足などは起動設定不正として拒否する。実料金へ更新する時は公式情報と確認日を記録して再起動する。確認済みcontext-limitがあれば出力予約枠を引いた上限を適用する。

## 選定と暫定判断

- 主選択は必須で、予算不足でも自動削除・途中切断しない。メソッドcosine上位3、共通語なしならpublicのソース順上位3、明示targetは必須。同じ型の解決済み呼出を最大2段補完する。constructor・フィールド・初期化宣言・型・package/importも保持する。
- CLASS_EXPLAIN/PROJECT_STRUCTUREは未採用メソッドの原文署名を別記し、本文の省略を明示する。AUTH_ANALYSISの主選択Securityは全構成メソッドを保持する。解析失敗は全文を残して予算判定する。
- 原文の行区間を合併し、同じ行に複数宣言がある場合は交差するメソッド全体へ拡張する。再整形せず、原行番号と省略範囲を表示する。根拠資料なので組み立てた断片の再コンパイルは目的にしない。
- 任意候補は`density=R/max(T_chunk,1)`、同点はR降順→相対パス。R=0を追加しない。初期最大3メソッド＋同型呼出補完と必要宣言を候補にし、全文と余裕が収まる場合だけ追加。大きい候補が入らなくても後続を試す。主選択の必須分不足時は任意追加しない。
- 会話保存・履歴APIは後続範囲なので初回質問のみ、履歴0件を明示する。固定promptの履歴なしラベルは計数する。後続実装では実履歴を同じ材料へ一度だけ含め、6往復／25%枠と最新往復不足時の拒否を実装する必要がある。
- 保存済みjavaSourcesだけを利用する。設定ファイル本文は追加読込しない。主選択の設定ファイルは不可理由を返し黙って成功にはしない。外部送信前の除外・マスキング方針を決めるIssue #2の後続事項を維持する。Java／質問内の秘密を安全に除去する保証もないため、外部送信機能を追加する前に確認する。
- previewはメモリのみ、5分・最大100件。設定は不変で起動ごとにconfigVersionを更新する。requestDigestは長さ付き文字列と整列した一意な選択IDから作り、入力の曖昧な結合を防ぐ。
